Windows games,on your Mac.

Ember launches Windows games on Apple Silicon Macs. It selects an engine and graphics translator for each game, and retries with another translator if a game crashes during launch. It also includes Ember's own frame generation, image enhancement, and frame pacing. See the test scope and performance measured on an M4 Pro for each game below.

Reading the frame-rate records

Check the conditions, too.

These figures were measured on this Mac (M4 Pro). They include earlier measurements and changes through October 23. Results vary with the scene and settings and are not latency guarantees.

Game fps

Frames actually rendered by the game. Rates vary by map, resolution, and settings, even within the same game.

Display output fps

With frame generation enabled, this includes intermediate frames. Ember Flow and in-game frame generation are listed separately.

Test scope

Menus, local bot matches, trials, and online play are distinguished. Stutter and hangs are noted even when average fps is high.

Measurements from October 18–20

Responsiveness and stutter matter, too.

Ember Flow · Frame generation

Rosetta · D3DMetal smooth mode recorded internal presentation latency of 24.2 → 14.1 ms in the Stellar Blade demo at FHD with MetalFX off.

Ember Spark · Input latency management

DXMT low-latency mode automatically sets the display queue to 2 frames when the game keeps up with its fps cap, or 3 when it cannot. A synthetic GPU-load test measured median input-to-display latency of 49.7 → 37.8 ms and game fps +26%. Valheim with FEX, FHD, a 60 fps cap, and frame generation off measured internal latency of 10.2 → 5.6 ms.

Lost Ark · Frame-rate improvement

Retrieving GPU results sooner raised game fps by +7% (50.2 → 53.7) in a crowded scene. A separate realignment comparison reduced the median of per-second maximum frame times from about 23–29 → 17–20 ms.

Features built by Ember

More than getting games to run on a Mac

Once a game is running, Ember's own engines get to work: Ember Flow · Forge · Tone · Flare · Pulse · Boost · Kindle · Kiln · Spark · Lens · Guard. Select ibeside a name to see how it works and its measurements.

Ember FlowFrame generation

Fill the gaps between frames while managing latency

Ember's own frame generation engine draws a new frame between two game frames. Even as a game fluctuates around 60~100fps, it fills the display evenly within your monitor's refresh rate (such as 120 or 144Hz).

  • Fill as neededFills only the gaps, without slowing the game itself.
  • Motion compensationBuilds intermediate scenes along the paths objects move.
  • Text protectionEmber Guard Keeps nameplates and HUD text from smearing.
  • Latency managementDrains the queue and uses low-latency mode to keep input responsive. If frame generation delays the display, it pauses briefly to prioritize response. Overwatch (D3DMetal), with frame generation on: latency 44.5 → 25.2 ms. Lethal Company (Rosetta · DXMT, 4K) recorded internal latency of 51.5 → 43.0 ms.
  • Even outputFixed frame generation stopping whenever latency briefly exceeded its limit. Stellar Blade (D3DMetal, 144Hz) display output used to vary between runs from 72~117 fps; the average rose from 109.6 → 116.7 fps, with latency increasing by less than 1 ms. Rosetta D3DMetal smooth mode changed its presentation method, taking Stellar Blade FHD latency from 24.2 → 14.1 ms, output 116.6 → 119.2 fps(QHD 24.2 → 15.8 ms, 114.0 → 118.8 fps).
  • Fewer long pausesIn one Once Human session (Rosetta · D3DMetal · 4K), pauses over 50 ms fell from 6 → 0. This is a single-session result; an improvement in overall output variation was not confirmed.
  • HDR color protectionFor HDR (PQ) games in D3DMetal, frame generation stops and original frames are displayed to preserve color. The Witcher 3 displayed without color or brightness errors in our test.
  • Frame generation HUDEmber Lens Shows FG ON and LAT (latency) in the corner of the game. If frame generation pauses, it also shows the actual reason.
  • Flow neural networkA neural network trained by Ember reads motion to create intermediate scenes. It is the default in Auto mode, and at 4K its cost is about 60% of the previous method.
  • Frame generation engine 1.6In Lost Ark (FEX · DXMT), skipped neural frame generation frames fell from 76~133 per 120 seconds → 0.
  • Ripples and foliageGenerates frames even in scenes with scattered fine detail, without repeating original frames.
  • Generate frames before upscalingWith MetalFX, frame generation runs at the pre-upscale resolution to reduce GPU load. Lost Ark game fps rose by 10%.

More features

Ember Wayfinder
Tries launch combinations in sequence for games that fail to start, then lets you save one. It first tries known launch options and recommended translators, then other supported translators and engines. If a Steam game crashes under Rosetta, it also checks the FEX path sharing the same installation.
Find, save, and undo

Tests with add-ons disabled, using only installed bottles. It will not start while a game or Wine launcher is running, or test anti-cheat games. Games and launchers opened by each trial are closed afterward, and files changed during testing are restored.

Launch-success detection, settings saving, and undo were tested in Valheim and The Witcher 3. The Witcher 3 success detection relies on indirect evidence from a D3DMetal hook, game window, and CPU activity. It does not guarantee gameplay or long-term stability.

A discovered combination is saved only when you choose “Save these settings.” Add-ons are preserved, and you can turn them on and recheck if you wish. Use “Revert settings” to undo a saved configuration.

Frame Check
Measures the same scene with different settings and shows which is faster in numbers.
Shader cache
Keeps shaders once created to reduce stutter from the second launch onward.
Fast synchronization (msync)
Handles Windows program synchronization directly inside Ember, making it 22× faster.
Launcher support
Runs Steam, Epic, Battle.net, and STOVE inside Ember, keeping your Steam login. EA app and GOG GALAXY were tested as far as their login screens; completed login, game installation, and launch still need separate tests. Installed games appear on Home. An FEX Steam startup hang was also fixed: The Witcher 3 launch tests went from 6 hangs in 16 attempts → 0 in 23 (these are not successful gameplay counts).
Uninstall games
Use the ⋯ menu beside Play. Steam, STOVE, and Battle.net use their launcher's official uninstall; other games go to the Trash. The path and size are shown first.
Older-game cutscenes
Includes AVI video codecs so cutscenes in older games do not appear as black screens.
Older-game audio
Preserves audio in older games using DirectSound.
Korean fonts
Automatically selects fallback fonts to keep Korean text in Windows programs from appearing as boxes.
Windows compatibility mode
Game files and settings stay in separate bottles. Choose whether programs are told Windows 11, 10, or 7; this does not install Windows. Running 32-bit games with FEX is a separate experimental feature that must be enabled in settings.
Add games from folders or ZIP files
Games without installers can be added to your library by choosing a folder or opening a ZIP file.
Dialog alerts
Ember notifies you when a game is waiting at a notice or confirmation dialog. Check the dialog yourself to continue.
Microphone permission dialog
Limits voice-input initialization time so a microphone permission dialog does not leave the game unresponsive. Microphone input may not be ready while the permission dialog is pending.
Per-game launch options
Set frame caps, resolution (FHD · QHD · 4K), and upscaling for each game. Options are grouped into Display, Ember Flow, Frames & Latency, Image Refinement, Experimental, and Advanced.
Launch logs
View what went wrong in the logs and ask Ember about them directly. Ember AI suggests actions based on the game and recent settings changes, keeping applied settings reversible.
Ember updates
An automatic update bar shows progress from checking for new versions through download and installation.
Send diagnostic logs
Choose what to include and review a preview with personal information masked. Logs are sent only with your consent. Saving to a file keeps them on your Mac. Privacy Policyexplains retention and deletion.
Battery and heat
Battery Mode is opt-in. Performance comes first by default.
