1What we publish

These components require or are intended for source provision. This list does not establish source completeness.

  • Wine — Wine based on CrossOver’s published source (Rosetta engine), Wine 11 ARM64 (FEX engine), and the x86_64 build. LGPL
  • DXMT — DirectX 11·12 to Metal translator (d3d11·d3d12·dxgi·winemetal). LGPL
  • FEX — Engine for translating x86 code on ARM (ARM64EC). MIT
  • DXVK — CrossOver published-source build. zlib
  • GStreamer, GLib, FFmpeg, and others — Video and audio playback libraries. LGPL
  • wine-gecko — MPL
  • 7 Wine changes from ForgePlay — Originals and notices

The 10/20 installation includes improvements to GPU result readback and waiting in DXMT, plus automatic adjustment of the low-latency presentation queue. Changes within open-source components, including interfaces that call EmberCore, are also covered by source disclosure.

2Accompanying materials

  • Ember’s changes to the original source (patch series) and a list of modified files
  • The configuration and scripts used for the actual build, with rebuild instructions
  • A copy of the original archive and its SHA-256
  • How to identify the source used for the distributed binaries

3What remains private

The Ember app, our independently developed EmberCore engine (frame generation, text protection, image refinement, and more), trained models, and the Ember character and artwork.

Changes, bridges and actual linked inputs within LGPL components must be provided as required by their licenses. Full correspondence between the current installed app and published source is unverified.
