Game Mode launch approach — ForgePlay

Ember’s Game Mode launch approach—using a game-category host app for each game so that macOS recognizes it as a game—was informed by ForgePlay Game Mode. Ember wrote its own code, including LaunchServices launching, automatic Game Mode detection, and Ember Boost. No ForgePlay Game Mode code (GPL-3.0-only) is included.

11Lost Ark boss HUD

The boss HUD reads only text visible on the game screen, locally on your Mac, and displays it at a larger size. It does not read or modify game memory, send keyboard or mouse input on your behalf, or access game files or communications.
