Ember Flow프레임 보간

진짜 프레임 사이에 한 장을 더 넣고, 입력 지연은 줄입니다

Ember가 직접 만든 보간 엔진이 두 프레임 사이에 새 프레임을 그려 넣습니다. 게임이 60~100fps로 흔들려도 화면은 120Hz에 맞춰 채웁니다.

  • 보충형모자란 만큼만 채워서 게임 자체를 늦추지 않습니다.
  • 움직임 보정물체가 움직인 길을 따라 중간 장면을 만듭니다.
  • 글자 보호Ember Guard 이름표와 HUD 글자가 번지지 않게 지킵니다.
  • 지연 관리대기열을 비우고 저지연 모드로 입력 반응을 지킵니다.
  • 보간 HUDEmber Lens 화면 구석에 FG ON과 LAT(지연)를 바로 띄웁니다.
  • Flow 신경망Ember가 학습한 신경망이 움직임을 읽어 중간 장면을 만듭니다. 자동에서 기본으로 쓰고, 4K에서 드는 비용은 기존 방식의 약 60%입니다.
  • 물결·풀숲무늬가 잘게 흩어지는 장면에서도 원본 프레임을 반복하지 않고 보간합니다.
  • 확대 전 보간MetalFX와 함께 쓰면 키우기 전 해상도에서 보간해 GPU 부담을 줄입니다. 로스트아크 게임 fps가 10% 올랐습니다.

HDR 게임은 HDR10(PQ) 10비트 출력을 그대로 맥의 HDR 화면에 보냅니다. SDR 게임도 밝은 곳만 살려 HDR로 보여 주고, 글자·메뉴는 그대로 둡니다.

Rosetta 없이 도는 ARM 번역을 더 빠르게

  • 빠른 API 전환시스템 호출 한 번에 27 ns → 5 ns.

  • 미리 번역Ember Kindle 쉬는 동안 번역해 두어 첫 실행 끊김을 줄입니다.
  • 구조x86-64 코드를 ARM64로 번역합니다. 엔진은 게임마다 고를 수 있습니다.

Ember에 들어 있는 오픈소스, Ember가 고친 LGPL 구성요소, 따로 설치하는 구성요소의 고지와 소스 안내를 앱의 설정 → 라이선스·고지에서 볼 수 있습니다. 같은 내용을 라이선스와 고지 페이지에도 실었습니다.

그 밖의 기능

Frame Check
같은 장면을 설정만 바꿔 재고, 어느 쪽이 빠른지 숫자로 보여 줍니다.
셰이더 보관
한 번 만든 셰이더를 보관해 두 번째 실행부터 끊김을 줄입니다.
빠른 동기화(msync)
윈도우 프로그램의 동기화를 Ember 안에서 직접 처리해 22배 빨라졌습니다.
런처 지원
스팀·에픽·배틀넷·STOVE를 Ember 안에서 실행합니다. 스팀 로그인도 그대로 유지됩니다.
옛 게임 컷신
AVI 영상 코덱을 넣어 옛 게임의 컷신이 검은 화면으로 나오지 않습니다.
옛 게임 소리
DirectSound를 쓰는 옛 게임의 소리도 그대로 납니다.
한글 글꼴
윈도우 프로그램의 한글이 네모로 깨지지 않게 대체 글꼴을 자동으로 맞춥니다.
호환 환경
Windows 11·10·7과 32비트 레거시 환경을 게임마다 골라 씁니다.
게임별 실행 옵션
프레임 상한, 해상도(FHD·QHD·4K), 화면 확대를 게임마다 따로 정합니다.
실행 기록
무엇이 잘못됐는지 기록을 바로 보고, 그 기록을 그대로 엠버에게 물어볼 수 있습니다.
배터리·발열
배터리 모드는 원할 때만 켭니다. 기본은 성능 우선입니다.
미리 준비
전원이 연결돼 있고 게임을 안 할 때 Ember Kindle이 번역을, 셰이더 보관이 셰이더를 미리 준비해 둡니다.
