라이선스와 고지

Ember에 들어 있는 것과 그 출처

Ember는 많은 오픈소스 위에서 만들어졌습니다. 어떤 구성요소를 어떤 라이선스로 쓰는지, Apple 구성요소와 AI 모델은 어떻게 다루는지, 이 웹사이트의 자료와 수치는 어디서 왔는지 적었습니다. Ember 버전 1.0 기준입니다.

고지 확인 범위 Ember 자체 구성요소 Ember가 고친 LGPL 오픈소스 그 밖의 오픈소스 별도로 준비하는 AI 모델 따로 설치하는 것 출처 표기 이 웹사이트에 쓴 것 상표 게임 화면 성능 수치 측정 조건 로스트아크 보스 HUD

1고지 확인 범위

이 목록은 출시판 기준입니다. 2026-10-25 확인한 로컬 개발 앱에는 D3DMetal과 Metal Shader Converter도 들어 있습니다. 출시 배포물과는 구분해야 합니다.

공개 저장소의 실제 접근, 배포 바이너리와 전체 소스의 대응, 사용자 수정 라이브러리의 교체 실행은 미확인입니다.

앱의 진단용 영상 18개는 원본과 재배포 조건이 미확인입니다. Wine 글꼴과 중첩 패키지의 개별 고지 대응도 추가 확인이 필요합니다.

2Ember 자체 구성요소

© 2026 Ember. 모든 권리 보유.

Ember 앱과 자체 엔진 EmberCore(Ember Flow, Guard, Forge, Tone, Flare, Pulse, Spark, Kiln, Boost, Lens), Ember가 만든 학습 모델과 엠버 캐릭터·그림은 Ember의 독점 소프트웨어·자산입니다. 사용 조건은 이용 약관을 따릅니다.

EmberCore는 오픈소스 구성요소와 분리된 별도 라이브러리입니다. Wine·DXMT 같은 LGPL 구성요소 안에 들어간 Ember의 수정과 연결부는 그 구성요소의 LGPL을 따르며 소스를 공개합니다.

LGPL 소스와 권리

LGPL 구성요소의 소스 제공 경로와 빌드 안내는 소스 페이지에서 확인할 수 있습니다. 현재 배포 바이너리 전체에 대한 소스 대응성은 검증 중입니다.

Ember를 받은 날부터 최소 3년 동안 realnoma@naver.com로 요청하면 해당 LGPL 조항에서 요구하는 대응 소스와 재링크 자료를 매체·전송 비용만 받고 제공합니다. 이 제안은 Ember를 받은 누구에게나 유효합니다.

라이브러리 교체 방법은 소스 패키지에 안내되어 있습니다. 현재 앱 사본에서 사용자가 고친 라이브러리를 실제로 불러오는 시험은 미완료입니다.

Ember의 이용 약관은 LGPL 구성요소를 고치거나, 고친 버전을 디버깅하려고 역분석하는 것을 막지 않습니다.

12로스트아크 보스 HUD

보스 HUD는 게임 화면에 보이는 글자만 맥 안에서 읽어 크게 다시 보여 줍니다. 게임의 메모리를 읽거나 바꾸지 않고, 키보드·마우스 입력을 대신 보내지 않으며, 게임 파일이나 통신을 건드리지 않습니다.

그래도 게임 이용은 각 게임의 이용 약관을 따릅니다. 쓰기 전에 해당 게임의 약관을 확인해 주세요.

Ember는 Apple, Microsoft, 각 게임사와 관계없는 독립 프로젝트입니다. 게임 이름과 화면은 각 권리자의 것입니다.

Ember왜 만드나라이선스와 고지이용 약관개인정보 처리방침오픈소스 소스 코드
